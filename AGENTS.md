# Workspace rules

- Run commands from ../ongoing_work; keep generated files, builds, environments and logs there.
- This repository contains product source and its own documentation. Do not generate ZIPs unless requested.
- Common/shared is authoritative; use Common/tools/sync_shared.py to verify/publish tracked snapshots.
- Do not modify the user-managed Brand_Images directory without a task requiring it.
- Preserve existing user edits. Do not add production data, credentials, caches or binaries to Git.
- Cross-repository architecture and migration details: ../Common/docs/repository-layout.md.
